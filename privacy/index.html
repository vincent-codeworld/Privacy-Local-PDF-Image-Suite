Privacy promise

LocalPDF tools run entirely in your browser using client-side JavaScript and WebAssembly. When you select a file, it is read with the browser File API and processed in memory on your device.

  • No file uploads: tool pages do not POST your documents to our servers.
  • No account: we do not ask for email or passwords to use the tools.
  • Verify yourself: open browser DevTools → Network, run a conversion, and confirm there is no request carrying your file bytes.
  • Downloads: results are saved with a local blob download link.

This site may be hosted on Cloudflare. Serving the static app is not the same as receiving your documents. Static assets (HTML/CSS/JS) load over HTTPS; your PDF/image contents are not part of those requests after the page loads.

If we later add optional server features (for example OCR), they will be clearly labeled and opt-in, with a separate privacy note.
